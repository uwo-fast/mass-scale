# Datasheets and standards

Third-party documents the design refers to, as uploaded to the
[OSF project](https://osf.io/me9a8) on 2020-04-09. Their publishers hold the
copyright; see [`../../LICENSING.md`](../../LICENSING.md). The paper's
reference numbers are given so its citations can be followed.

| File | What it is | Publisher | Paper ref. |
| --- | --- | --- | --- |

| `TAL221.pdf` | TAL221 miniature load cell (M3 threads), 100–1500 g | HTC-Sensor | [79] |
| `hx711F_EN.pdf` | HX711 24-bit ADC for weigh scales | Avia Semiconductor | [63] |
| `GDM1602K-Extended.pdf` | GDM1602K 16 × 2 character LCD module | Xiamen Ocular | [62] |
| `ScaleCommProtocol5199M1.pdf` | SCP-0499 Scale Serial Communication Protocol (1999), which the firmware implements to Level 2 | Scale Manufacturers Association | [65] |
| `loadcellapplicationtestguidelineapril2010.pdf` | Load Cell Application and Test Guideline (April 2010) | Scale Manufacturers Association | [61] |

Two further documents that were on OSF, the operator manuals of the Denver
Instruments A-160 and APX402 balances used for comparison, are not kept here;
