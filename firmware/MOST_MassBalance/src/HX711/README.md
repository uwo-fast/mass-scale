# HX711 library (vendored)

The [HX711 Arduino library](https://github.com/bogde/HX711) by Bogdan Necula
and Andreas Motl, `MIT` (see [`LICENSE`](LICENSE)), at the commit the
MOST_MassBalance library's git submodule pointed to: `75dfed4`, released as
version 0.7.4 (2020-03-22). Only the two source files, the licence and
`library.properties` are copied; the upstream repository also has examples,
documentation and build files.

`MOST_MassBalance.h` includes it as `HX711/src/HX711.h`, so this directory
keeps the upstream layout.
